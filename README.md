# Aroma White — Texas Café Portfolio

Static responsive portfolio website built for GitHub Pages.

## Run locally
Open `index.html`, or run a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `aroma-white`).
2. Upload **the contents of this folder** to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will provide a live URL after deployment.

The project uses relative asset paths, so it works from a repository subpath on GitHub Pages.

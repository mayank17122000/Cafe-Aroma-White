AROMA WHITE V8 — PORTFOLIO DEMO

Open index.html in a modern browser.
For best local testing, run a simple static server in this folder, for example:
  python -m http.server 8000
Then open http://localhost:8000

GitHub Pages:
- Upload the entire contents of this folder to the repository root.
- Keep the relative assets/ paths unchanged.
- index.html is the entry point.

This is a fictional portfolio café. The checkout is a frontend simulation and does not process payments or send orders.
